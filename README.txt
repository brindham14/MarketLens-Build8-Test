This is a separate build. It does not replace your existing MarketLens site.

HOW TO TEST
1. Keep index.html, core.js, app.js, styles.css, data/, update_data.py and .github/ together.
2. Open this folder using a local web server (recommended) or publish it to a NEW GitHub repository for private testing.
3. Do not open index.html directly as a file:// URL; browsers may block local JSON fetches.
4. For a local server with Python installed, open a terminal in this folder and run:
      python -m http.server 8000
   Then open http://localhost:8000

KNOWN LIMITATIONS / STILL PENDING
- The supplied summary has 2,193 stocks; history.json has close-only history for 705 stocks. It is not a full OHLCV candle dataset.
- Index constituent membership is not verified by the supplied files; this build does not claim an accurate Nifty Total Market constituent filter.
- The supplied daily stage field is retained from the generator; it is not represented as the full weekly Weinstein stage model.
- Pattern flags (VCP, Pocket Pivot, Flag, breakout) are the supplied generator's calculations. They have not yet been independently reconciled against chart pattern detection.
- OHLCV candle files are still absent from the supplied data folder. The chart therefore uses close-only history for the 705 symbols with history; the other symbols show an explicit unavailable message. No TejHQ fallback is claimed or used.
- Backtest engines, persistent cross-page watchlists/tags, custom scans, alert delivery and mobile/browser QA remain pending.
- The GitHub Actions workflow runs update_data.py and commits data/ outputs. Test it in a separate repository before using it in production.

PATTERN AUDIT NOTES (Build 2)
- Popular Scans now exposes the pipeline's existing cup, Darvas breakout, Darvas-in-box and multi-year breakout flags.
- Pattern results are algorithmic candidates, not chart-confirmed discretionary pattern classifications.
- Cup & Handle rule checks price depth/duration/rim/handle criteria but does not prove a smooth rounded U.
- VCP rule uses three fixed 20-session windows and a volume-contraction proxy; inspect the chart before trading.
- Flag rule uses a recent 25-session peak, a prior 40-session low and pullback criteria; inspect the chart shape.
- Pocket Pivot and Darvas flags are generated by update_data.py.
- 'Breakout today' is pivot-crossing logic; '52-week high breakout' (b50) is a separate 50-session high condition.
- Missing pattern fields are treated as unavailable, not as false values.
- These corrections do not yet reconcile chart-side pattern drawings or validate all OHLCV histories.

BUILD 8 — WORKSPACE, SWING & SAVED SCAN UPDATE

Added:

- Stock tags can be edited from the stock detail modal and are shown in screener, Swing ideas and workspace.

- Watchlist rows reference the current supplied summary snapshot. Stocks no longer present in the snapshot will not display in the table.
- Tags are user annotations and do not change scan qualification or source calculations.
- No deployment has been performed. The original live GitHub Pages website remains untouched.
